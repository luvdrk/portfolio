Panzi — AI smart pantry

A pantry app built with a team, running on iOS with real accounts. Snap a photo of a shelf and Panzi logs each item, reads the use-by date off the label or estimates one, warns you before food goes off, and suggests Filipino recipes from what you already have — finishing a recipe takes its ingredients back out of the pantry. Behind it sits the admin console I built: live usage, the user community, saved recipes, AI API costs and an audit log.

  • Shelf scanning & date reading
  • Use-by estimates & reminders
  • Pantry-only recipe matching
  • Step-by-step cook mode
  • Ask Panzi chat
  • Admin console & API costs
